# Content Sources & Verification Log

Every resource in THE AWAKENING and THE IDENTITY RESET is defined once in `content/library.ts`.

The build environment can't reach YouTube directly, so each video was checked through web search (October 2026):

- **Direct link** (`yt(id)`): the video ID and title appeared together in search results.

Before launch, spend about 10 minutes clicking every link once. Re-uploads get taken down and channels rename videos.
