## One-line thesis
Meta Value Rules allow advertisers to set bid multipliers (e.g., +50%) for higher-value audience attributes (age, location, device, placement) to nudge the algorithm toward higher-LTV/ROAS conversions rather than chasing cheap, low-quality leads/sales [00:13, 01:17, 04:55].

## Method (ordered, step by step)
1. **Access Meta Ads Manager:** Open your Meta Ads Manager account [02:45].
2. **Navigate to Settings:** Click on the main menu icon on the left navigation bar and select **Advertising settings** [02:49].
3. **Open Value Rules:** Locate and click on the **Value rules** card under "Your business" [02:53].
4. **Initiate Rule Set Creation:** Click **Create a rule set** [02:56].
5. **Acknowledge Warning:** Check the mandatory box stating: *"I understand my overall cost per result may increase when using value rules"*, then click **Create a rule set** [03:03 - 03:12].
6. **Define Target Criteria:** Choose up to 3 criteria to define your preferred segment [03:25]:
   * Options include: *Conversion location, Age, Gender, Device platform, Mobile operating system, Location, Placement* [03:26 - 04:26].
7. **Set Bid Adjustment Percentage:** Under *"Choose how much to bid on outcomes that meet your criteria"*, set the percentage multiplier (e.g., **Increase bid by 50%**) [04:55 - 04:59].
8. **Name & Save:** Assign a **Rule name** (e.g., *Facebook Feed*) and click **Next** / **Save** [04:54, 06:02].
9. **Alternative (Ad Set Level Setup):** Alternatively, navigate directly into a campaign ad set, scroll to **Value rules**, click **Create a rule set**, and apply rules specifically to that ad set instead of account-wide [06:28 - 06:45].

## Meta ads specifics
* **Scope Levels:** 
  * **Advertising Settings Level:** Rules apply globally across **all ads** in the ad account [06:16 - 06:24].
  * **Ad Set Level:** Rules apply **only to adverts within that specific ad set** [06:30 - 06:36].
* **Rule Criteria Options (transcribed from UI) [03:26]:**
  * *Conversion location* (e.g., website vs. app vs. messaging) [03:29]
  * *Age* (specific age ranges) [03:42]
  * *Gender* (men or women) [04:01]
  * *Device platform* (desktop or mobile) [04:10]
  * *Mobile operating system* (iOS or Android) [04:20]
  * *Location* (countries, regions, states, designated market areas) [04:24]
  * *Placement* (Facebook Feed, Instagram Feed, Stories, Reels, etc.) [04:25, 04:51]
* **Bidding Mechanism:** Uses supply-and-demand auction bidding. Increasing the bid (e.g., by 50%) gives Meta permission to bid higher in competitive auctions to win impressions for higher-value user profiles instead of settling for low-cost, low-converting placements/users [05:00 - 06:00].

## Mistakes / warnings called out
* **Incorrect Use Risk:** Misconfiguring rules can increase your cost per lead without delivering higher-value customers [00:36].
* **Chasing CPL/CPA over Value:** Optimizing strictly for the lowest CPL or CPA causes Meta to target cheap, low-intent users who rarely purchase or have low lifetime value [00:13, 01:42, 02:01].
* **Hard Exclusions:** Hard-excluding mobile users or entire placements (like Facebook Feed) in ad set targeting limits algorithm efficiency. Weighting bids via Value Rules is superior to hard exclusions [02:30 - 02:44, 04:35 - 04:48].
* **Stakeholder Expectation Mismatch:** Cost per lead/result will often rise when Value Rules are activated. Media buyers must brief bosses or clients beforehand to focus on ROI/ROAS rather than CPL [03:03, 06:05, 06:40 - 06:48].

## Top 5 takeaways for a clothing brand media buyer
1. **Weight High-AOV Devices Instead of Hard-Excluding:** If iOS app users have higher Average Order Value (AOV) than Android users, set a +20% to +50% Value Rule for iOS rather than completely disabling Android targeting [04:12 - 04:23].
2. **Prioritize High-LTV Demographics via Bidding:** Use historical Shopify customer data to identify core spending age brackets (e.g., 25–44) and apply Value Rules to bid higher for them without locking out broader audience reach [01:11, 03:42 - 04:00].
3. **Optimize Placement Bids:** Rather than turning off Facebook placements to run 100% Instagram, set a Value Rule favoring Instagram Feed/Reels so Meta bids aggressively where conversions yield higher cart sizes while still capturing baseline Facebook sales [04:27 - 04:48].
4. **Choose Global vs. Local Application:** Apply Value Rules at the Advertising Settings level for account-wide rules, or at the Ad Set level when testing specific high-ticket sub-collections [06:16 - 06:36].
5. **Realign Client / Brand Benchmarks:** Shift reporting KPIs away from Cost Per Purchase (CPP) toward overall Return on Ad Spend (ROAS) and total net revenue, as CPP will naturally increase when bidding on competitive, high-value audiences [06:05 - 06:53].
