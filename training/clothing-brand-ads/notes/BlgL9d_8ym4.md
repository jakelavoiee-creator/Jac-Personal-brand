## One-line thesis
Clothing brands can eliminate hours of repetitive AI briefing ("prompt tax") by building 3-layer Markdown Skill files in Claude that lock in brand voice, customer psychology, and operational constraints across all copy workflows [00:18, 03:28, 05:06].

---

## Method (ordered, step by step)
1. **Identify the Prompt Tax:** Recognize where 3–5 hours/week are wasted re-explaining brand identity, customer personas, and tone in fresh AI chat windows [00:10].
2. **Initiate Skill Builder Chat:** Open a new Claude chat window to draft the skill specification file [05:30].
3. **Execute Skill Creation Meta-Prompt:** Send an initial prompt instructing Claude to act as a skill creator for a clothing brand [06:09].
4. **Answer the 5 Core Diagnostic Questions:** Feed Claude precise details regarding brand voice, customer persona, non-negotiables/rules, and content types [06:43-07:14].
5. **Generate & Save the `.md` File:** Have Claude package the answers into a properly structured `skill.md` file [07:15]. Click **Save Skill** to save it directly into Claude (`Customize` -> `Skills` -> `Personal Skills`) [01:54, 09:05, 09:26].
6. **Test in a Clean Chat:** Open a fresh chat window and issue a minimal, zero-context prompt referencing the saved skill name [09:50-10:11].
7. **Audit & Debug Prompt Conflicts:** Test the skill against 5 sample prompts. If an output slips off-brand, adjust the prompt wording rather than destroying the skill file [11:33-11:45].
8. **Build a Skill Stack:** Expand from a single brand voice skill into a stacked system containing specialized skills for Meta Ad Creative, Customer Service, and Product Descriptions [14:19-14:48].

## Claude / AI workflow

### System Setup
- **File Format:** Markdown (`.md`) saved under Claude's `Customize` -> `Skills` menu [01:54, 09:26].
- **Voice Dictation Tool:** Whisper Flow (used to rapidly dictate detailed brand context to AI) [05:35, 07:41].

### 3 Layers Required for a Clothing Brand Skill [03:28]:
1. **Voice Layer:** Tone adjectives, vocabulary rules, words to use, banned words (e.g., banning "premium" or "luxury" for raw streetwear brands) [03:40, 03:58].
2. **Customer Psychology Layer:** Emotional drivers, identity aspirations, how they want to feel wearing the brand [04:15-04:49].
3. **Constraints Layer:** Hard guardrails (e.g., never suggest discounts, never say "affordable", keep captions under 150 characters) [05:03-05:14].

### Verbatim Prompts & Inputs

#### Initial Skill Creator Prompt [06:09]:
> `"SO I WANT TO CREATE A SKILL FROM MY CLOTHING BRAND. I'LL DESCRIBE MY BRAND VOICE, MY CUSTOMER AND THE RULES CLAUDE SHOULD ALWAYS FOLLOW. HELP ME BUILD A SKILLED FILE."`

#### Claude's 5 Diagnostic Questions [06:43]:
1. `"What should this skill help Claude do? For example: Write product descriptions, Create social media captions, Draft email/SMS copy, Write ad copy, All of the above"`
2. `"Tell me about your brand voice. How do you want to sound? (e.g., bold & unapologetic, inspirational, street/culture-forward, clean & minimal, humorous, etc.) Give me 3-5 adjectives or a short description."`
3. `"Who is your customer? Age, lifestyle, values, what they care about, what they're buying for."`
4. `"What are your non-negotiables — the rules Claude must always follow? Things like: never use certain words, always mention a specific brand value, never sound corporate, always use short sentences, etc."`
5. `"Do you want this skill to cover one type of content or multiple?"`

#### Verbatim Test Prompt (Zero Context) [09:56, 10:11]:

## Mistakes / warnings called out
- **Paying the "Prompt Tax":** Opening Claude and re-explaining brand tone, customer demographics, and product rules every session [00:01-00:15].
- **Useless Persona Prompts:** Using surface-level prompts like *"You are a helpful assistant for my clothing brand"*, which acts as a meaningless name tag rather than a skill framework [03:32-03:36].
- **Generic Fashion Buzzwords:** Allowing AI to insert generic industry fluff like "premium" or "luxury" when writing copy for raw, authentic streetwear brands [03:58-04:00].
- **The #1 Skill-Killing Mistake:** Uploading a skill file but failing to test it against conflicting user prompts. Explicit prompts override background skill rules (e.g., if a skill says *"Talk like a locker room"* [11:23] but the prompt asks for *"a professional description"* [11:27], Claude follows the prompt and ignores the skill) [11:02-11:31].
- **Blind AI Trust:** Failing to review AI outputs before publishing. *(Claude system warning cited: "Claude is AI and can make mistakes. Please double-check responses.")* [11:57].

## Top 5 takeaways for a clothing brand media buyer
1. **Eliminate the "Prompt Tax":** Save 3–5 hours per week by uploading a `.md` Skill file to Claude so every new chat automatically starts with full brand context [00:10, 01:46].
2. **Build the 3 Essential Skill Layers:** Ensure your brand skill specifies Voice (tone & banned words), Customer Psychology (identity aspirations), and Hard Constraints (no discounting, character limits) [03:28-03:42].
3. **Stack Function-Specific AI Skills:** Don't rely on one generic skill. Deploy separate, specialized skills for Brand Voice Copy, Meta Ad Creative (pre-loaded with winning ad angles), and Customer Service [14:19-14:38].
4. **Debug Prompts Before Editing Skills:** If AI outputs deviate from brand guidelines during testing, fix prompt contradictions first, as user prompts always take precedence over skill rules [11:32-11:45].
5. **Use Dictation for Deeper Briefs:** Use voice-to-text dictation tools (like Whisper Flow) to feed detailed, multi-minute brand briefs into AI 5x faster than typing [05:35, 07:41].
