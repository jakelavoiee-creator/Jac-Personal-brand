## One-line thesis
High-retention captions require a strict two-font hierarchy (clean sans-serif for context, expressive script for emotion) driven by three modular 10-frame eased kinetic presets (slide left, slide right, slide up) packaged into compound clips.

## Editing techniques

### 1. Two-Font Hierarchy (Context vs. Emotion)
- **What it is**: Dividing spoken words into primary (neutral, readable context) and secondary (expressive, visual accent) typefaces ([00:27]-[00:42]).
- **When to use**: On high-impact hook sentences and keyword punches. Never style all words identically, or visual hierarchy collapses ([00:34]).
- **Parameters**:
  - **Primary (Context)**: *Helvetica* (or *Tactic Sans*, *Neometric*, *Hiragino*) ([00:30]).
    - All-caps (`TT`), Bold (`B`), Character tracking: `-2`, Line spacing: `0`, Centered ([00:46]-[00:48], [01:29]-[01:36]).
  - **Secondary (Emotion & Accent)**: *Shelley Script LT Std* ([00:30], [05:24]).
    - Title case (`Tt`), Regular weight (disable Bold), Character tracking: `0` ([05:26]-[05:32]).
    - Scale: 10–25% larger than primary font (e.g., primary at 15–18pt, secondary at 20–25pt) ([04:56], [05:08], [05:33]).

### 2. High-Contrast Text Styling (Readability Shell)
- **What it is**: A clean outer stroke paired with a soft drop shadow to detach white text from complex video backgrounds ([00:49]-[00:54], [01:38]-[01:44]).
- **Parameters**:
  - **Fill Color**: Pure White (`#FFFFFF`).
  - **Stroke**: Solid Black (`#000000`), Thickness: `4` ([00:50], [01:40]).
  - **Drop Shadow**: Black (`#000000`), Opacity: `70%`, Blur: `15%`, Distance: `5`, Angle: `-45°` ([00:53], [01:42]-[01:44]).

### 3. Native Blur In/Out Micro-Transitions
- **What it is**: CapCut built-in blur animation applied to the text layer to soften entry and exit ([00:54]-[00:58], [01:46]-[01:51]).
- **Parameters**:
  - In Animation: `Blur In` | Duration: `0.6s` ([00:57], [01:50]).
  - Out Animation: `Blur Out` | Duration: `0.6s` ([01:50]).

### 4. 10-Frame Kinetic Movement Presets
- **What it is**: Reusable 10-frame keyframe animations for text entrance ([02:08]-[03:37]).
- **Parameters (Timeline base: 30–60 fps, 10 frames = ~0.16–0.33s)**:
  - **Keyframe 0 (Entry)**:
    - `Blend Opacity`: `0%` ([02:24]).
    - *Preset 1 (Slide Left)*: Position X: `-600`, Y: target anchor (approx. `-549` to `-600` above chin) ([02:05], [02:31]).
    - *Preset 2 (Slide Right)*: Position X: `+600`, Y: target anchor ([03:10]).
    - *Preset 3 (Slide Up)*: Position X: `0`, Position Y: `-1200` ([03:26]).
  - **Keyframe 10 (Rest)**:
    - Advance 10 frames (`Shift` + `Right Arrow`) ([02:14]-[02:16]).
    - `Blend Opacity`: `100%` ([02:12]).
    - Position X: `0`, Position Y: target rest coordinate ([02:18]-[02:20]).
  - **Interpolation / Easing**:
    - Open Variable Speed Graph Editor (`Alt` + `E`) ([02:39], [02:51]).
    - Apply smooth Ease-Out / S-curve interpolation using shortcut `Shift` + `W` on selected keyframes ([02:43]-[02:45]).

### 5. Color Highlighting
- **What it is**: Isolating the single focal word in a phrase with a contrasting warm color ([05:51]-[06:01]).
- **Parameters**:
  - Color: Vivid Golden Yellow (`#FDA600` / `#FFCC00`) ([05:56]-[05:58]).
  - Applied to the accent script font or critical semantic anchor ([05:58]).

## Motion graphics / animations
- **Glassmorphic Floating Cards ([00:07]-[00:22])**:
  - Semi-transparent rounded rectangles with neon border glows and floating keyframe drift.
- **Modular Kinetic Caption Presets ([01:00], [03:37]-[03:44])**:
  - Three master clips created once on the timeline, renamed:

- **Compound Clip Bundling**:
  - Each animated word layer is wrapped into an independent Compound Clip (`Alt` + `G`) before stacking, locking the internal animation so position offsets don't break keyframe values ([03:53]-[03:56], [04:44], [04:59], [05:34]).

## Mistakes / warnings
- **Styling Every Word the Same ([00:34]-[00:36])**:
  - Treating all text equally causes visual fatigue. Primary font handles clarity/context; secondary font captures emotional spikes.
- **Rebuilding Motion from Scratch Every Time ([01:05]-[01:09])**:
  - Manually placing keyframes for each caption line causes severe editor burnout and sluggish turnaround. Build three master template presets and duplicate compound clips.
- **Ignoring Easing Curves ([02:27]-[02:47])**:
  - Linear motion looks amateur and robotic. Always apply speed variable easing curves (`Shift` + `W` in CapCut) to give smooth deceleration into rest.

### 1. Generating ASS Subtitle Script with Dual Fonts & Motion Easing
Use Python to generate an Advanced SubStation Alpha (`.ass`) file with two distinct styles (Helvetica Bold Context vs. Shelley Script Accent) and `\move` / `\t` easing tags.

```python
# generate_aura_captions.py
import math

ass_header = """[Script Info]
ScriptType: v4.00+
PlayResX: 1080
PlayResY: 1920
ScaledBorderAndShadow: yes

[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Style: Context,Helvetica,58,&H00FFFFFF,&H000000FF,&H00000000,&HB2000000,-1,0,0,0,100,100,-2,0,1,4,5,2,40,40,450,1
Style: AccentScript,Shelley Script LT Std,78,&H0000A6FD,&H000000FF,&H00000000,&HB2000000,0,-1,0,0,100,100,0,0,1,4,5,2,40,40,450,1
Style: HighlightYellow,Helvetica,68,&H0000D7FF,&H000000FF,&H00000000,&HB2000000,-1,0,0,0,100,100,-2,0,1,4,5,2,40,40,450,1

[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
"""

# Example: 10 frames at 60fps = ~167ms transition
# Slide Left: start x = -60, end x = 540; y = 1450
# Slide Right: start x = 1140, end x = 540; y = 1520
# Slide Up: start y = 1750, end y = 1380; x = 540

events = [
    # 00:00.00 -> 00:01.00: "IF" (Slide Up)
    r"Dialogue: 1,0:00:00.00,0:00:01.20,Context,,0,0,0,,{\move(540,1650,540,1380,0,167)\fad(167,100)\t(0,167,\fscx100\fscy100)}IF",
    # 00:00.20 -> 00:01.20: "YOU" (Slide Left)
    r"Dialogue: 2,0:00:00.20,0:00:01.20,Context,,0,0,0,,{\move(-60,1440,540,1440,0,167)\fad(167,100)}YOU",
    # 00:00.40 -> 00:01.20: "WANNA" (Slide Right)
    r"Dialogue: 3,0:00:00.40,0:00:01.20,Context,,0,0,0,,{\move(1140,1500,540,1500,0,167)\fad(167,100)}WANNA",
    # 00:00.60 -> 00:01.20: "DROP" (Slide Left - larger context)
    r"Dialogue: 4,0:00:00.60,0:00:01.20,HighlightYellow,,0,0,0,,{\move(-60,1570,540,1570,0,167)\fad(167,100)}THE HEAT",
    # 00:00.80 -> 00:01.20: "Aura Miami" (Secondary Font Accent)
    r"Dialogue: 5,0:00:00.80,0:00:01.20,AccentScript,,0,0,0,,{\move(540,1800,540,1650,0,167)\fad(167,100)}Aura Miami",
]

with open("aura_captions.ass", "w", encoding="utf-8") as f:
    f.write(ass_header + "\n".join(events))
print("ASS subtitle file generated.")
```

### 2. Burn-In & Audio Master Pipeline via FFmpeg
Combine raw video, background music ducked by `-20dB` under narration, and burned-in `.ass` subtitles:

```bash
ffmpeg -y -i raw_founder.mp4 -i lofi_beat.mp3 \
  -filter_complex "\
    [1:a]volume=0.10[bgm]; \
    [0:a][bgm]amix=inputs=2:duration=first:dropout_transition=2[aout]; \
    [0:v]subtitles=aura_captions.ass:fontsdir=./fonts[vout]" \
  -map "[vout]" -map "[aout]" \
  -c:v libx264 -preset fast -crf 18 -pix_fmt yuv420p \
  -c:a aac -b:a 192k \
  aura_miami_ad_output.mp4
```

## Top 7 takeaways for editing Aura Miami founder and UGC ads

1. **Establish a Strict Brand Two-Font Hierarchy**: Use an aggressive heavy grotesque font (e.g., *Helvetica Black*, *Tactic Sans*, or *Neometric*) for product specs/streetwear context, and a luxury calligraphy script (e.g., *Shelley Script*) for elevated brand words like `"Luxury"`, `"Miami"`, or `"Drop"` ([00:27]-[00:42]).
2. **Apply the Standard Streetwear Legibility Shell**: Raw UGC lighting varies wildly; lock every text layer to `#FFFFFF` with a `4px` black outline and a `70%` opacity drop shadow (`blur 15px`, `distance 5px`, `angle -45°`) to ensure legibility across busy Miami backdrop shoots ([00:49]-[00:54]).
3. **Template the 3-Way Movement Bank**: In CapCut or Premiere/After Effects, save the exact 10-frame slide-in curves (Left: `X -600`, Right: `X +600`, Up: `Y -1200` to rest with `Shift` + `W` S-curve easing) at the end of every timeline. Never keyframe from scratch ([01:05]-[01:09], [03:44]-[03:49]).
4. **Pack Words into Compound Clips Before Layering**: Convert animated text presets into compound clips so you can adjust font sizes (e.g., resizing emphasis words to 18–20pt) without distorting the underlying animation keyframe paths ([03:53]-[03:56], [04:44]).
5. **Anchor Text Above the Chin / Microphone Line**: Keep all stacked captions in the lower third above the founder's collar/mic level ([02:05]). This avoids TikTok/Reels UI dead zones and keeps eyes anchored on facial expressions.
6. **Deploy the Single-Word Color Pop**: Highlight only one key hook word per phrase with vivid golden yellow (`#FDA600`) to direct attention to the value proposition or limited-stock drop callout ([05:51]-[06:01]).
7. **Pattern Interrupt Every 2 Seconds in the Hook**: In the first 3 seconds of founder ads, flank the speaker with floating mockups or glassmorphic cards backed by crisp whooshes and bass drops to combat sub-second scroll-away behavior ([00:00]-[00:15]).
