My toolchain: ffmpeg + Python (+ Higgsfield for generated elements). Notes translate every technique into reproducible parameters.

- `queue.txt`: tutorials (Jac's own example links go first when he sends them)
- `notes/<id>.md`: per-video notes: techniques, hook construction, captions, sound design, pacing, motion graphics, ffmpeg recipe
